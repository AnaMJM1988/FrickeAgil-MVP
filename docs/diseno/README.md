# Diseños del MVP FrickeÁgil

Esta carpeta contiene los prototipos de interfaz del sistema FrickeÁgil.

## Módulo médico

- Ficha clínica simplificada.
- Visualización de fechas de cobertura de medicamentos y próximo control médico.
- Alerta de posible brecha de cobertura.
- Opciones de receta normal y receta diferida, sujetas a validación y autorización médica.

Los diseños utilizan información ficticia y representan funcionalidades propuestas para el prototipo académico.
